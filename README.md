# Saad's public shoebox

Archived snapshots and previews of media references for Saad Chinoy's work, linked from the about-page timeline.

Each folder holds a `snapshot.pdf` (full page capture) and a `preview.png` (first-screen preview) for one referenced item.

Pilot items: 2014 Yogyakarta, 2023 re:publica EcoPrints, 2024 BuildPeace Manila, 2025 Maker Faire Cairo, 2025 re:publica Repurposing 3D Printers, 2026 Fab City Awards, 2026 GOSH Kathmandu, 2026 Shaping Hearts Punggol.
